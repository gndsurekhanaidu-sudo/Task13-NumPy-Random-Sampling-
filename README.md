# Task13-NumPy-Random-Sampling-
Description
This project demonstrates how to generate random numbers and select random samples using NumPy.
Objective
Understand random data generation and the importance of reproducibility in data science experiments.
Tools Used
Python
NumPy
Jupyter Notebook
Tasks Performed
Generated random integers and floating-point numbers.
Selected random samples from an array.
Used a random seed to produce reproducible results.
Created a small simulated random dataset.
Key Learning
Random sampling is useful for simulations, testing, and data science experiments. Setting a random seed helps reproduce the same results when the code is run again.
How to Run
Install NumPy: pip install numpy
Open the notebook in Jupyter Notebook.
Run the cells to view the random sampling examples.
